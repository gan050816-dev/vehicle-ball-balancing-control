# 任务三蓝牙调参上位机

> **已停用的历史上位机。** 当前主工程已删除蓝牙协议、服务及对应测试，
> 本工具不能再与当前固件握手或调参。UART0通信仍保留，但只通过PB0向
> USB转TTL发送T3 CSV日志；PB1当前不接线。保留本目录仅供历史参考。

电脑连接蓝牙上位端；蓝牙下位模块通过透明串口连接TI：模块TX接PB1
（UART0_RX），模块RX接PB0（UART0_TX），双方共地。串口固定为9600、8N1。
蓝牙配对密码只负责建立无线连接，参数帧仍使用序号和CRC16校验。

## 启动

```powershell
python -m pip install -r D:\eletri\upeer\requirements.txt
python D:\eletri\upeer\bluetooth_tuner.py
```

在Windows蓝牙设置完成配对后，系统通常生成一个传出COM口。打开上位机，
选择该COM口并点击“连接”。握手成功后软件依次读取11项参数，再以100 ms周期
显示任务三状态。一次只修改一个参数；点击对应“写”，必须看到从机回传的
“实际值”才算生效。参数只保存在RAM，TI复位后恢复固件默认值。

## 协议

```text
B5 62 | version | command | sequence | length | payload | CRC16-CCITT
```

CRC覆盖`version`至`payload`，初值`0xFFFF`、多项式`0x1021`，CRC低字节先发。
最大载荷32字节。从机响应沿用请求序号；上位机600 ms未收到匹配响应时重发，
最多2次。

| 命令 | 方向 | 说明 |
|---|---|---|
| `0x01` | 上位机→TI | 握手 |
| `0x10` | 上位机→TI | 读取参数ID |
| `0x11` | 上位机→TI | 写参数ID和int32定点值 |
| `0x20` | 上位机→TI | 读取一次状态 |
| `0x21` | 上位机→TI | 开关周期状态流，周期100～1000 ms |
| `0x81/0x90/0xA0/0xA1` | TI→上位机 | 信息、参数、状态、确认 |
| `0xE0` | TI→上位机 | 错误响应 |

开放参数包括Kp、Kd、启动角、PD接管位置、预测时间、助推进入/退出速度、
控制软角度上下限、步进速度和加速度档。赛题`+50/-50 mm`目标、5秒超时、
完成判据和机械硬角度边界不能通过蓝牙修改。

状态回传包括应用状态、T3阶段、步进状态、原始/滤波球位置、球速、控制目标角、
X42命令/测量位置代理、P/N/V结果、CRC/格式错误和接收溢出计数。
