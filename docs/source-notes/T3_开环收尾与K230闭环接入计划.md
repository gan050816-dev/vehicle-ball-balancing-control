> 版本固定启动角为`-20.50°`，正向到达窗为`+46.5～+52.0 mm`且无速度门槛，
> 负向完成窗为`-52～-47 mm`连续5帧并满足`|v|<=20 mm/s`。用户已确认当前

## 1. 当前结论

上一版从0闭环追踪`+50 mm`时，小球只到`+31.4 mm`后静止。静止时纯PD
理论输出约`-6.40°`，不足以继续克服摩擦，因此原始坐标没有达到`+50 mm`，
状态机也没有进入负向段。

当前版本改为：先用有实测依据的固定向下角克服启动摩擦，再根据预测位置
提前进入正向接近PD；实际到达`+50 mm`后立即把目标切到`-50 mm`并连续
使用PD。暂不加入积分，一次只验证启动与接管变化。

固定角启动、`Kd=0.057`版本已通过全量10项主机测试和CCS构建；用户随后
实测正向峰值约`+90 mm`，返回时撞到合页，说明固定角启动已解决
`+31.4 mm`静止，但速度阻尼不足。当前待烧录版本只把`Kd`提高到0.100，
也已通过全量10项主机测试和CCS 20.5.1 Debug Clean + Full Build
（0错误、0警告）。本轮没有修改K230、OLED、主程序、步进服务、SysConfig、
UART帧格式或X42协议。

## 2. 当前控制顺序

```text
启动后等待第一帧新鲜视觉
  → 固定相对角-20.05°向+X启动
  → x_predict达到+30 mm：进入+50 mm接近PD
  → 接近段连续3帧v<=10 mm/s：重新使用-20.05°助推
  → v>=25 mm/s：退出助推，恢复接近PD
  → 原始x>=+50 mm：记录P/V+，立即切换-50 mm连续PD
  → 原始x<=-50 mm：记录N/V-，但不作为DONE前提
  → 连续5帧位于-60～-40 mm且|v|<=50 mm/s：DONE
  → 5000 ms仍未完成：FAULT
```

不增加小球运动边界。

## 3. 正向固定角与提前接管

平衡位置14.9 mm，旧实测能到达`+50 mm`的启动位置为7.9 mm，二者相差
7.0 mm。模数1、40齿齿轮每圈理论移动125.664 mm，因此：

```text
theta_drive = -7.0 / 125.664 * 360
            = -20.05°
```

第一帧有效视觉到达后，控制器只发送一次离散`-20.05°`命令，随后保持该角，
不在正向起步阶段逐渐减小驱动力。

视觉预测保持：

```text
x_predict = x_filtered + 0.120 * v_filtered
```

当`x_predict>=+30 mm`时进入接近PD。以`v=70 mm/s`为例，接管发生在原始
位置约`+21.6 mm`，距目标还有28.4 mm。当前X42发送层从`-20.05°`调整到
接近水平约需5个4.30°步进，即约400 ms；70 mm/s在400 ms内约移动28 mm，
因此预测`+30 mm`比等到原始`+40 mm`再接管更匹配执行器响应。

## 4. 接近PD与低速再助推

当前PD参数：

```text
e = x_target - x_predict
theta = -0.344 * e + 0.100 * v_filtered
Ki = 0
theta_min = -28.65°
theta_balance = 0°
theta_max = +14.32°
```

正向接近段若滤波速度连续3个新鲜帧不高于`+10 mm/s`，说明小球可能再次
被摩擦停住，控制器通过连续跟踪接口把目标恢复为`-20.05°`。滤波速度达到
`+25 mm/s`后退出助推并继续`+50 mm`接近PD。实际原始坐标达到`+50 mm`
优先级最高，无论是否正在助推，都立即切换负目标并清除助推状态。

## 5. 负向控制为什么不等待-40 mm

到达`+50 mm`的同一帧立即启用目标为`-50 mm`的预测PD。历史负向速度约
215～269 mm/s；若等到原始`-40 mm`才开启PD，400 ms执行器过渡期间可能
继续移动86～108 mm，制动明显过晚。因此负向段从`+50 mm`开始全程使用PD，
而不是增加固定`-40 mm`接管点。

## 6. 时间预算

历史5组数据：

| 阶段 | 最小 | 平均 | 最大 |
|---|---:|---:|---:|
| 到达`+50 mm` | 1349 ms | 1491 ms | 1707 ms |
| 换向后到达`-50 mm` | 1787 ms | 1873 ms | 2075 ms |
| 两段合计 | 3222 ms | 3364 ms | 3566 ms |

最差历史两段合计后仍剩约1434 ms。当前目标是：

```text
+50 mm：约2.0 s前到达
-50 mm：总时间约4.0 s前到达
稳定检查：保留约1.0 s
```

低速再助推在60 ms确认后立即恢复固定角，不等待积分逐渐建立，因此比上一版
永久停在`+31.4 mm`更有利于满足5 s要求。以上只是基于历史数据的预算，
当前版本仍须一次实机验证。

## 7. 视觉和执行器约束

- K230当前源码每20 ms发送状态，TI只消费最新有效序号。
- 位置EMA系数0.5；速度使用跨2帧实际时间差并再做0.5 EMA。
- 超过500 mm/s的异常速度观测被拒绝。
- 连续120 ms无新鲜视觉时停止使用旧坐标并命令相对平衡角`0°`。
- 启动500 ms仍无第一帧有效视觉时同样回`0°`。
- X42速度20 RPM、加速度档100。
- 跟踪目标最短80 ms发送一次，只保留最新目标；等效变化不足0.3 mm不发，
  单次最多变化1.5 mm，约等效4.30°。
- 中间目标等待`Receive`但不等待逐点到位；编码器跟随和FAULT检查保持不变。
- DONE时结束跟踪并发送停止命令，保持当时电机角度。

## 8. 首次操作

1. K230保持当前已部署版本，不按PB27，不重新标定固定O点。
2. 烧录SHA-256为
   `E4DDD4249ADC62FB57FD1B2383C0C7FBC1258714497DEE418E58386A5E431B7F`
   的Debug固件，断电人工回机械下限，上电完成HOME/LEVEL。
3. 先不放球或遮挡视觉启动T3，确认500 ms后回`0°`、5 s显示FAULT。
4. 确认X42逐条返回地址2的`Receive`，没有`E2/EE`，齿条没有停顿或突跳。
5. 重新上电回平，在固定O点放球，只运行一次T3，手保持在复位键附近。
6. 预期先固定向下运动，随后在到达`+50 mm`之前开始减小向下角或制动；
   实际达到`+50 mm`后立即向负目标回调。
7. 发生碰撞、方向错误、`E2/EE`或齿条异常时立即复位，不连续重复。

## 11. 当前参数诊断与手动调参顺序

- 固定`-20.05°`启动到预测位置`+30 mm`之前不使用PD，因此这一段不受Kp/Kd
  调整影响。
- 原始位置达到`+50 mm`后目标从`+50`阶跃为`-50 mm`。以`x=+50 mm`、
  `v=+70 mm/s`计算，当前未限幅目标角约`+44.29°`，最终固定饱和在
  `+14.32°`；0.057版也同样饱和。因此换向初段两版命令完全相同。
- X42目标每80 ms最多变化等效1.5 mm，即约4.30°。即使后续两版PD目标角
  已经不同，执行器仍可能先沿相同斜率追赶，导致宏观轨迹近似。
- 若只手调PD，第一轮保持`Kd=0.100`，只把`Kp=0.344`降到`0.250`；若仍
  撞合页，再单独试`Kp=0.200`。负向峰值安全但目标附近振荡时，才把Kd按
  0.02一步增加；若停在目标带外且低速不再前进，则把Kp按0.02～0.03回升。
- 若两次降低Kp后轨迹仍几乎不变，停止继续盲调PD，下一步必须观察PD目标角
  和X42编码器角，或修改负目标阶跃/角度饱和/执行器目标斜率中的一项。
