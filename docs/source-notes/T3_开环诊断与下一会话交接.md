## 5. 当前实际参与编译的T3模式

当前源码：

```c
#define TASK3_REVERSE_FRICTION_DIAGNOSTIC 1U
```

因此当前固件是临时反向摩擦诊断版，不是正式T3顺序。软件齿条轨迹为：

```text
时间/ms：       0      650     2600    3100    3600完成
软件位置/mm： 14.9 → 19.9 →  9.9 → 19.9 → 14.9
绝对伸长/mm： 37.4 → 42.4 → 32.4 → 42.4 → 37.4
```

各阶段含义：

1. `0～650 ms`：齿条上升到19.9 mm，小球先向`-X`加速。
2. `650～2600 ms`：齿条下降到9.9 mm，先制动小球的`-X`速度，然后使其
   向`+X`返回。
3. `2600～3100 ms`：齿条上升到19.9 mm，制动`+X`运动。
4. `3100～3600 ms`：齿条回到14.9 mm水平位置。
5. `3600 ms`：当前任务完成；总超时常量仍为5000 ms。

用户实机确认“启动后先向`-X`”，与当前诊断模式一致。

## 7. 对现象的正确物理判断

“最远点停顿一瞬间后返回”是换向点，不是平衡点：

- 最远点瞬间，小球沿管方向的速度约为0；
- 因为随后向`+X`返回，所以合加速度已经指向`+X`，通常不为0；
- 如果速度和加速度都为0，小球不会立即返回。

当前程序在650 ms后主动把齿条从19.9 mm切换到9.9 mm，即把管子的加速度
方向从`-X`切换到`+X`。因此“小球继续靠惯性向`-X`运动、速度降到0、再向
`+X`返回”与当前诊断轨迹相符，不能单独归因于摩擦不均。

这次实验能够证明：

- 电机和齿条能够产生`-X`方向的运动；
- 650 ms后的反向倾斜能够消除`-X`速度并使小球返回；
- 当前观察到的是动态换向，不是最终稳定。

这次实验尚不能证明：

- 正式T3能先到`+50 mm`再到`-50 mm`；
- 小球已经进入`-50±10 mm`目标区；
- 3100 ms回平时刻适合正式T3；
- 4.5 s时能够在目标区保持；
- 摩擦模型或开环拟合已经完成。
