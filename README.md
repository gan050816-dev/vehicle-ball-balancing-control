# 车载小球平衡运动控制系统

## 项目简介

本项目是基于 TI MSPM0G3507 与 K230 的车载小球平衡运动控制系统，包含底盘循迹、双轮速度闭环、小球视觉测量、摆杆角度控制、步进电机通信、任务状态机、安全保护和主机侧逻辑测试。

## 目录结构

- `firmware/H_BallBalance_MSPM0G3507`：当前主控 CCS 工程。
- `firmware/task2-legacy`：保留的早期任务工程，用于追溯控制逻辑演进。
- `vision/k230`：K230-A 小球识别、标定和串口通信程序。
- `vision/k230-b-streaming`：K230-B 独立图传和录像程序，Wi-Fi 参数已替换为占位值。
- `tools/bluetooth-tuner`：保留的上位机蓝牙调参工具；当前主工程未启用该链路。
- `tools/vision-utils`：视觉与 RTSP 辅助脚本。
- `docs/source-notes`：项目开发过程、控制参数和阶段性验证记录。

## 主要内容

- 八路灰度传感器循迹与丢线保护。
- 双轮编码器速度 PID、速度斜坡、换向保护和堵转检测。
- K230 小球位置测量、固定零点和动态捕获流程。
- 任务 3 的位置/速度 PD 控制。
- 任务 4 至任务 6 的滚球闭环与底盘加速度前馈。
- X42 闭环步进电机命令、应答、状态和实时位置解析。
- OLED 菜单、运行状态、偏差统计和故障提示。
- UART 中断接收队列、主循环解析、数据新鲜度和超时保护。
- 主机侧纯逻辑单元测试。

## 环境依赖

- MCU：TI MSPM0G3507，LQFP-64。
- SDK：MSPM0 SDK 2.10.0.04。
- SysConfig：1.27.1。
- 编译器：TI Arm Clang 4.0.4 LTS。
- 视觉端：K230 / CanMV Python 环境。

更详细的引脚、协议、任务状态和控制参数见主工程中的 `README.md` 与 `docs/source-notes`。

## 使用方法

主机侧测试入口：

```powershell
pwsh -NoLogo -NoProfile -File .\firmware\H_BallBalance_MSPM0G3507\tests\run_all.ps1
```

## 验证状态

测试通过只能证明纯逻辑与配置契约成立，不能代替 CCS 构建、板卡启动、电气波形、串口协议和整车验证。

当前整理副本的主工程测试结果为 18 项通过、1 项失败。失败项是 `task3_controller` 在命令跟踪状态转换处的既有断言；其余测试（包括协议、传感器、驱动、安全、菜单和应用控制器）均通过。早期 `task2-legacy` 工程的 16 项测试全部通过。为避免改变原控制行为，整理阶段没有修改该算法问题。
