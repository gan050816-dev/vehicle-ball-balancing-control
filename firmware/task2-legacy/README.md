> **独立历史调参工程，不是当前主工程。** 当前交付工程为

> 不设31 s正常停车；T4/T5/T6只在OLED显示最大正负偏差，偏差不触发FAULT。

目标板为 MSPM0G3507 LQFP-64。这个子工程独立维护八路灰度循迹、双轮速度
闭环、OLED 菜单、K230-A 钢球位置、X42 电机轴角度反馈和任务四角度域
PD+前馈，验证后再由人工复制最终参数到主工程。齿条只作为机械传递件，
控制器、步进服务、跟随误差和OLED不计算或显示齿条位置。

## 上电与按键

八路巡线模块采用直接 GPIO 数字输出。产品资料要求每次上电至少等待 20 s
让探头稳定；首次使用，或安装高度、环境发生变化后，需按模块 KEY1 重新录取
黑线和白底。软件不使用阻塞延时，20 s 稳定过程可与人工确认机械下限和
HOME/LEVEL 流程同时进行。

1. 断电时把齿条人工放到 22.5 mm 机械下限。
2. 给整车上电，并确认巡线模块也已供电。
3. OLED 显示 `HOME`，确认机构确实在下机械限位后按车上 KEY1。
4. 系统依次停止、使能、清零并移动到当前初始水平角`42.64°`；X42 的接收
   确认、`Prf_TF`和实时编码器角度全部满足后才显示菜单。
5. 确认巡线模块上电已满 20 s 后，KEY2循环选择任务，KEY3确认并启动。
   T2立即启动；T4先显示`WAIT`，取得新的有效K230固定O点帧后自动启动，
   不需要再次按键。确认前已经在途的旧帧不会触发自动启动。
6. KEY4是复位兼紧急制动：底盘立即刹车，X42停止并解除使能，取消当前任务
   和K230等待并回到`HOME`；重新人工放低齿条后，再按KEY1归正。

车上四键固定为：

| 按键 | 引脚 | 功能 |
|---|---|---|
| KEY1 | PA15 | 仅在`HOME`执行X42清零和水平角归正 |
| KEY2 | PB27 | 在`SELECT`循环选择`T2 ↔ T4` |
| KEY3 | PB23 | 确认并启动；运行中不作为停止键 |
| KEY4 | PA29 | 随时紧急停止并复位到`HOME` |

OLED状态顺序为`HOME → LEVEL → SELECT → RUN`；T4等待视觉时显示`T4 WAIT`，
故障显示`FAULT`，按KEY4可安全复位到`HOME`。T2和T4真正启动后，OLED
第四行都以`RUN:xxxx.xx s`显示运行时间；T4的`WAIT`时间不计入，停车后
保留最终时间，KEY4复位或下一次启动时清零。

T4故障第一行会继续显示现有子原因：`T4 FAULT START`表示启动条件不满足，
`T4 FAULT VISION`表示视觉无效或超过120 ms，`T4 FAULT X42`表示X42服务
故障，`T4 FAULT CMD`表示角度跟踪命令被拒绝。该显示只暴露已有故障类别，
不改变任何判定、超时或安全动作。

发生`T4 FAULT VISION`时，故障瞬间的视觉状态会锁存，页面改为：

```text
T4 FAULT VISION
D:032 AGE:0147ms
CRC:0002 OVF:0001
RUN:0003.12s
```

`D`是视觉拒帧诊断位：001无完整帧、002球无效、004未标定、008目标点无效、
016多候选、032低置信度、064重复序号、128时间戳冻结、256位置跳变；前五项
可叠加。`AGE`是故障瞬间距离最后一帧被接受数据的时间。`CRC`和`OVF`分别是
从本次T4真正启动起新增的K230协议校验错误和UART接收队列溢出次数。四位显示
超过9999时封顶；数据只用于定位，不改变120 ms超时、视觉接受条件或安全动作。

K230固定黄点协议问题已经通过实车启动验证，当前
`RUN_STATUS_T4_DIAGNOSTIC=0`，OLED恢复调参数据：

```text
T4 RUN
AP:0300 X:-040.0
X:-003.7 A:-20.15
RUN:0002.78s
```

`AP`是本轮底盘运动剖面实际达到的峰值命令加速度，单位`mm/s²`；第一行
`X`是本轮绝对值最大的球位置并保留其正负号；第三行`X/A`分别是当前球位置
和X42相对水平点的实测电机角度。编码器10 ms速度量化后二次差分噪声过大，
当前不把它冒充实测加速度。正常或安全停车后第一行锁存原因：`STOP TIME`、
`STOP LINE`、`STOP STALL`或T2的`STOP FIN`，峰值和最终运行时间继续保留。

## 两种菜单

赛道理论周长为 `3000 + 1000*pi = 6141.59 mm`。

| OLED | 用途 | 速度与加速度 | 停止条件 |
|---|---|---|---|
| `T2` | 任务二完整一圈 | 350 mm/s，最大 800 mm/s² | 9 s 后识别 A 线，20 s 超时 |
| `T4` | 任务四保持 O 点并完整跑一圈 | 0～8 s 为 208 mm/s，之后 244 mm/s；最大 300 mm/s² | B 点由人工判定；启动后 31.00 s 正常停车 |

T2加加速度上限为2000 mm/s³；T4为减小启动时约`-30 mm`的小球峰值并给
视觉反馈和X42目标跟随留出余量，改为800 mm/s³，即每10 ms加速度最多变化
8 mm/s²。主机逐周期仿真结果：

- T2 实际峰值约 792 mm/s²，理论整圈约 17.97 s。
- T4 启动实际达到并且不超过300 mm/s²；8 s位移约1554.07 mm，
  理论整圈约26.84 s。

T4最大加速度继续保持已确认的`0.30 m/s²`。位置/速度反馈采用当前T3的
角度域初始增益；启动峰值主要通过运动剖面加速度角度前馈处理。

## 任务四钢球闭环

T4 在 KEY3 确认时向 K230-A 发送 `A5 5A 91 00 91`，强制使用固定机械 O 点，
不使用 PB27 动态捕获。启动前必须收到新的有效帧，要求：

- `VALID=1`、`CALIBRATED=1`、`TARGET_CENTER_VALID=1`；
- 非多候选，置信度不低于 650；
- 新序号；同一序号最多执行一次控制；
- K230 时间戳不能冻结，相邻位置变化对应的速度不能超过 500 mm/s；
- 最后有效帧超过 120 ms 时立即进入安全故障。

结合任务三实测最大球速约269.4 mm/s，视觉层不使用会增加约一帧延迟的
三点中值滤波。位置采用系数0.5的EMA；速度使用约80 ms的两帧窗口后再
做系数0.5的EMA；按120 ms延迟预测当前位置。每个新视觉序号、且距上次控制
不少于40 ms时执行：

```text
x_pred(mm) = x_filtered(mm) + 0.120 s * v_filtered(mm/s)
angle_feedback(deg) =
    0.344 deg/mm * x_pred(mm)
    + 0.057 deg/(mm/s) * v_filtered(mm/s)
angle_ff(deg) = -0.06717 deg/(mm/s²) * a_profile(mm/s²)
angle_relative = clamp(
    angle_feedback + angle_ff,
    -28.65 deg,
    +14.32 deg)
angle_absolute = 42.64 deg + angle_relative
```

正`x`表示小球远离合页，正相对电机角用于把球加速回`-X`方向。正向起步
加速度300 mm/s²时，初始前馈为`-20.15°`，绝对目标约为`22.49°`；反向
加速度给出相反前馈，但总角度仍受`+14.32°`上限保护。运动剖面在每次启动前
清零，前馈使用上一10 ms控制节拍的加速度，不继承上次停车状态。该前馈来自
现有机构和0.30 m/s²启动加速度的初步估计，尚未通过实车辨识。

PD内部期望角每40 ms最多变化`4.30°`；它不会直接形成电机命令队列。X42
层只保留最新期望角，并以最后一次实际发出的角度为基准：最短40 ms发送一次、
变化小于`0.86°`不发送、单次最多变化`4.30°`，等效角速度上限107.5°/s。
20 RPM对应120°/s；T4的800 mm/s³跃度通过初始前馈系数映射为约
53.74°/s，低于X42层107.5°/s目标斜率和20 RPM理论能力，并为视觉反馈修正
保留余量。发送仍必须等待上一命令Receive，且健康查询优先，不会以40 ms
周期无界堆积旧命令。

连续跟踪不要求每个中间目标独立到位，但控制应答、状态、使能、堵转保护、
查询超时和接收溢出仍持续检查。开始跟踪后有500 ms宽限；随后编码器角度
相对最后实际发送目标的误差超过`8.59°`且持续400 ms时进入故障。正常结束
会排队返回`42.64°`水平绝对角；`0x36`反馈超过`84.51°`硬角边界会立即
FAULT，其他故障或KEY4会停止并解除使能。

步进服务只保留角度坐标：正常绝对角初始范围为`2.86°～81.65°`，硬边界为
`84.51°`，T4相对控制范围对应绝对角`13.99°～56.96°`。这些值用于保持
现有机械安全边界，但必须在实物上直接以电机编码器角度重新核对；运行时没有
齿条毫米、齿轮周长或摆杆长度换算。

## 端口表

| 对象 | 外设 | 引脚 | 配置 |
|---|---|---|---|
| X42 | UART1 | TX PA8、RX PA9 | 115200、8N1、FIFO 关闭、RX 中断 |
| K230-A | UART3 | TX PB2、RX PB3 | 115200、8N1、FIFO 关闭、RX 中断 |
| OLED | I2C0 | SDA PA28、SCL PA31 | 400 kHz |
| KEY1～KEY4 | GPIO | PA15、PB27、PB23、PA29 | 上拉、低电平按下 |
| 巡线逻辑 X0～X3 | GPIO | PB20、PA24、PB25、PB26 | 输入；黑线低有效 |
| 巡线逻辑 X4～X7 | GPIO | PB10、PB14、PA17、PA7 | 输入；黑线低有效 |

产品板丝印为 X1～X8，工程按零基编号记为 X0～X7：产品 X1 对应逻辑 X0，
产品 X8 对应逻辑 X7。按产品正面标注方向，X0 作为左侧、bit0、负循迹误差，
X7 作为右侧、bit7、正循迹误差。若实际安装把模块旋转 180°，必须交换接线
或反转软件位序，不能只调 PD 符号。

UART ISR 只读字节并写入独立有界环形队列；协议解析、滤波、控制和日志状态均在
主循环执行。

## 循迹、计时与停车

- T2停车线要求至少4路灰度同时有效并持续3个控制周期（30 ms）；9 s前
  屏蔽起点线，20 s仍未完成则超时停车。
- T4不再使用灰度宽线作为正常停车条件，从底盘真正启动开始按10 ms控制
  周期计时，达到3100周期时在下一次电机目标输出前制动，即31.00 s停车。
- 丢线时降到120 mm/s，并沿最后偏离方向归正；1 s未找回则以
  `STOP LINE`停车。轮子堵转显示`STOP STALL`，31 s计时显示`STOP TIME`。
- T2 使用中心死区和分段 PD：小误差 `Kp=1、Kd=0.5`，大误差
  `Kp=2、Kd=0.5`。
- T4 使用 `Kp=0.75、Kd=0.25`、导数限幅 20，丢线差速
  120 mm/s。误差从0跳到70时差速由原来的100 mm/s降至57 mm/s，
  稳态由70 mm/s降至52 mm/s，以减轻慢速左右摆动。
- 转向反向需连续 2 个周期确认；底盘 PWM 每 10 ms 最大变化 80 ticks。

B 点没有软件检测、停车或计时事件，任务四的 A→B 时间必须由现场人员判定；
软件从实际启动持续运行至31.00 s正常停车。灰度仍用于T4循迹和丢线保护，
KEY4、堵转、视觉或X42故障仍可提前安全停车。
